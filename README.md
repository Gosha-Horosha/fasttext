Этот проект посвящен анализу и классификации новостных заголовков крупного российского издания Lenta.ru. В работе проводится сравнение современных методов эмбеддинга (FastText) и классических подходов машинного обучения (TF-IDF + ML) для задачи определения тематики новостей.

📌 Описание проекта
В рамках проекта решается задача многоклассовой классификации текстов. Мы определяем рубрику новости (например, "Экономика", "Спорт", "Наука и техника") только по её заголовку.

Основные этапы:
EDA (Разведочный анализ): Изучение распределения новостей по годам и тематикам.

Препроцессинг: Очистка текста, токенизация и лемматизация с использованием pymorphy2 и NLTK.

FastText:

Обучение Supervised-модели для классификации.

Автоматический подбор гиперпараметров (Autotune).

Unsupervised обучение для получения векторных представлений слов.

Визуализация семантической близости слов через t-SNE.

Классическое ML:

Векторизация через TF-IDF.

Сравнение моделей Logistic Regression и Random Forest.
